IRS TAX FILER WEBSITE COLOR SYSTEM
===================================

Recommended visual direction:
Clean blue, indigo, soft lavender, teal, and small amber highlights.
Do not use dark navy as the main page color.
Do not use pale gray text for important content.

PRIMARY COLORS
--------------
Primary Blue: #2563EB
Use for: primary buttons, active navigation links, links, important icons, selected tabs.

Primary Blue Hover: #1D4ED8
Use for: button hover states, active hover states, focused controls.

Deep Indigo: #172554
Use for: main headings, important titles, footer headings, strong text.

Indigo Light: #E0E7FF
Use for: selected backgrounds, soft heading highlights, active navigation backgrounds.

SECONDARY COLORS
----------------
Teal: #0F766E
Use for: secondary accents, service icons, verification accents, supporting buttons.

Teal Hover: #115E59
Use for: teal button hover states and active teal controls.

Teal Light: #CCFBF1
Use for: teal icon backgrounds, selected service backgrounds, soft information areas.

TEXT COLORS
-----------
